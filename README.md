# policy-tools

## 园区企业走访总结生成器（网页版）

这是一个可直接打开使用的单文件中文网页工具：`index.html`。

### 当前功能
- 表单字段完整：企业名称、走访人员、联系人、联系电话、企业实际办公地、企业基本情况、企业需求、园区解决方案。
- 一键生成“正式工作记录”风格走访总结，输出包含：
  - 标题与走访基础信息；
  - 一、企业基本情况；
  - 二、企业经营及业务情况；
  - 三、企业主要诉求；
  - 四、下一步服务建议。
- 保留并支持全部操作按钮：
  - `生成走访总结`
  - `复制总结`（含兼容回退逻辑）
  - `清空表单`

### 使用方式
1. 双击 `index.html`（或拖到浏览器）直接打开。
2. 填写表单后点击“生成走访总结”。
3. 点击“复制总结”可粘贴到台账系统。
4. 点击“清空表单”可开始下一家企业记录。
